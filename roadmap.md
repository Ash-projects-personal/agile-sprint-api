# Roadmap for agile-sprint-api

### Day 1: Story state machine
Add validation for story status transitions (TODO → IN_PROGRESS → IN_REVIEW → DONE) to prevent invalid state changes

### Day 2: Burndown chart endpoint
Calculate daily burndown data showing remaining story points over time for sprint tracking

### Day 3: Team capacity tracking
Add Team and Member models with capacity tracking to calculate sprint over/under commitment

### Day 4: CLI for quick entry
Build command-line interface for creating stories without curl, useful during standups

### Day 5: Retrospective notes
Add Retrospective model to store what went well, what didn't, and action items per sprint
